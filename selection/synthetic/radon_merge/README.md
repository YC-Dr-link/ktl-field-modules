# 라돈 기준 장비·시험품 합성 예시

형식을 눈으로 확인하기 위한 예시이며, 측정 데이터 행 수는 확인한 견본과 같다.
식별정보·날짜·측정값은 새로 만든 가짜 값이다. 실제 견본은 저장소에 포함하지 않는다.
모델명과 헤더 문구, 구분자 등 파일 구조만 확인한 형식을 따른다.

| 파일 | 형식 | 데이터 시작 행 | 측정 행 수 |
|---|---|---|---|
| `1023.csv` | 설명 9행 + 빈 필드 1행 + 열 이름, 쉼표 구분 10열 | 12 | 24 |
| `KTL_SYNTHETIC_20261022_130500.txt` | FRD2400V1, 설명 9행 + 열 이름, 탭 구분, 행 끝 탭 | 11 | 23 |
| `HJ25_SYNTHETIC_2026-10-22 11_50_00.txt` | FRD500, 설명 8행 + 열 이름, 탭 구분 | 10 | 22 |

시험품은 아래 12개이며, 기준 장비 3개와 합쳐 데이터 파일은 총 15개다.

| 시험품 파일명 패턴 | 형식 | 파일 수 | 데이터 시작 행 | 측정 행 수/파일 |
|---|---|---|---|---|
| `F4N_SYNTHETIC_001_*.csv`, `F4N_SYNTHETIC_002~003_*.txt` | FRD400 V2.0, 설명 8행, 열 이름 없음 | 3 | 9 | 22 |
| `FA25_SYNTHETIC_004_*.csv`, `FA25_SYNTHETIC_005~006_*.txt` | FRD500, 설명 8행 + 열 이름 | 3 | 10 | 22 |
| `GA21_SYNTHETIC_007_*.csv`, `GA21_SYNTHETIC_008~012_*.txt` | FRD500, 설명 8행 + 열 이름 | 6 | 10 | 22 |

시험품은 TXT 9개와 CSV 3개다. CSV는 사용자 요청에 따라 F4N 001번·FA25 004번·GA21 007번의
탭 구분을 쉼표 구분으로 변환한 합성 변형이며, 헤더 필드·날짜·측정값·22행을 유지한다.

이 합성 CSV를 실제 장비의 CSV 출력 형식으로 확정하지 않는다.

확인한 시험품 견본 4개 모두 측정 데이터가 22행이므로 생성기는 22행으로 고정했다.
FRD500 견본 3개는 같은 구조이며 각각 3개씩 합성한다(FA25 3개, GA21 6개).
생성기는 실제 견본 경로나 파일을 읽지 않으며, 실행할 때 같은 합성 시험품 12개를 재생성한다.
시험품별 고정 시드를 사용해 라돈 값의 변화 패턴과 온도·습도·기압의 수준 및 변동 폭을 다르게 했다.
FRD400은 기존 헤더를 유지하기 위해 라돈 값의 총합·최소·최대는 보존하면서 행별 배열과 변화를 조정했다.
F4N은 점으로 구분한 날짜, `S/N:`, `Data No :`, `Duration(min)` 및
`3day Avg/Min/Max` 헤더와 측정값 앞의 자리 맞춤 공백을 반영했다.

- 챔버 CSV 파일명은 작업일인 2026-10-23의 월일을 사용한 `1023.csv`이다. 나머지 파일은 구분용 접두어와 합성 표시, 측정 시작 시각을 포함한다.
- 합성 측정 기간은 2026-10-22~23이다. 실제 견본의 날짜·식별정보·측정값을 복제하지 않았다.
- 챔버 CSV 진행 상태는 Start 1행, Source Purge 1행, 1st Target Radon 20행, Zero Air Purge 2행이다.
- 공동 명세 NFR-03에 맞춰 UTF-8 BOM을 넣었다. 확인한 견본에는 BOM이 없었다.
- 줄바꿈은 CRLF이며, TXT 날짜 구분자는 각각 점과 하이픈이다.
- 장비 파일의 순번은 2자리 폭으로 왼쪽 정렬했다(`1 `~`9 `, `10` 이후). 한 자리 순번 뒤에 공백을 넣었으며, TXT는 탭, CSV는 쉼표로 열을 구분한다.
- 장비 파일은 1시간 간격이다. 챔버 CSV는 시작 기록과 다음 기록 사이만 5분이며 이후 1시간 간격이다.
- 세 파일의 측정 시각은 일부러 다르게 두었다. 동일 행 번호가 동일 측정 구간을 뜻하지 않는다.
- 이 예시는 형식 확인용이다. 병합 정답·평균 구간·계산 규칙은 포함하지 않는다.
- CSV 헤더의 `Acrivity` 표기는 확인한 형식을 유지했다.

## 생성·검증

저장소 루트에서 실행한다. 추가 의존성 없이 표준 라이브러리로 실행 가능하다.
테스트는 pytest에서도 수집된다.

```powershell
python selection/synthetic/radon_merge/generate_test_devices.py
python -m unittest discover -s selection/tests -p test_synthetic_radon_devices.py -v
```

## 확인

편집기에서 CSV와 TXT를 열어 헤더, 구분자, 위 표의 측정 행 수를 확인한다.
Excel은 날짜나 숫자 표기를 바꿔 표시할 수 있으므로 원문 확인에는 텍스트 편집기를 사용한다.
